# n8n 凭据准备

本文件只描述权限，不保存凭据值。`workflow.json` 与 fixtures 中不得出现真实账号、用户 ID、任务内容、访问令牌、连接串或 n8n credential ID。

| 凭据角色 | 最小权限 | 不允许的权限 | 权限不足或过宽时的处置 |
| --- | --- | --- | --- |
| 任务来源账号 | 只读指定任务清单或专用只读视图；返回稳定来源 ID 与更新时间 | 全账户读写、删除、分配成员、对外通知 | 无法收窄时使用专用清单；仍过宽则停在本地 fixture/草稿 |
| 日历账号 | 只读指定日历的忙碌时段；标题只在确有排序需要时读取 | 创建、修改、邀请、读取无关日历 | 只提供 busy/free；读取失败进入 `retryable_failed`，不用空日历代替 |
| 状态存储账号 | 仅能读写 `loop_tasks`、`loop_runs`、`loop_approvals`；生产中需唯一约束和条件更新 | 数据库管理员、跨 schema 访问、删库/改角色 | 权限错误进入 `failed_permanent`，不原样重试 |
| 模型或 Agent | 只接收 allowlist 脱敏任务包并返回固定 JSON | 原任务系统、审批表、凭据表、发送/删除/改期工具 | 任何外部动作工具都从生成工作流移除 |

凭据应保存在 n8n Credentials 或由部署环境注入。导出工作流前，使用 n8n 的凭据引用检查和仓库敏感模式扫描；不得把示例占位符替换成真实秘密后提交。
