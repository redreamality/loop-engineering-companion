# 《循环工程》配套代码

- `loop-engineering-companion/`：第 5 章每日计划循环的可运行 Python 项目，以及配套"循环成熟度自测表"成熟度证据查询的真实 PostgreSQL 夹具。
- [`loop-engineering-companion/n8n-daily-plan/`](loop-engineering-companion/n8n-daily-plan/README.md)：第 5 章低代码配方的 n8n 2.35.7 可导入工作流、错误路由、Schema、合成样本和验收日志。
- [`书外资料/`](书外资料/README.md)：各章从正文外移的模板、清单、演练和书中原版代码清单（含第 5 章 `书外资料/ch05/`），以及附录 A–E、循环成熟度自测表与完整来源说明；新旧章号对照见其 README。

每个项目的运行前提、代码类型、验证命令和边界写在项目自己的 README 中。正文里的代码块用于教学阅读；这里的锁文件、测试和样例文件是复制运行时的正式入口。
