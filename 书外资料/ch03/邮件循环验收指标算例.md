# 邮件循环验收指标算例

> 对应正文第 3 章 3.7 节表 3-6。来源：原第 4 章 4.7。

假设一周收到 100 封邮件，在本统计窗口内均已处理完毕：

- 其中 72 封无需人工审批、修改或接管就成功完成，另外 28 封经过了人工审批，则**自动处理率** = 72 / 100 = 72%。人工批准但没有修改任何文字的邮件仍属于这 28 封，不能计入自动处理率的分子。
- 若已处理的 100 封中有 2 封发生了严重错误，按邮件去重后的**严重错误率** = 2 / 100 = 2%。如果同一封邮件既发错了对象，又属于越权发送，在该比例中只计为一封；严重事件的次数可另外记录。
- **人工修改率**的分母是进入审批的 28 封，而不是全部 100 封；本例假设这 28 封都附有系统草稿。直接转入审批、由张总亲自撰写回复的投诉邮件没有系统草稿，应单独统计，不计入人工修改率。

口径说明：

- 如果还有邮件在排队，收件总数不能直接作为“已处理”的分母。
- 统计窗口、任务类型和“已处理”的定义要先固定。
- 分母为零时记为“无适用样本”，不能当作 0% 或 100%。
- 重复与遗漏数要覆盖全部邮件，不能只在已经顺利处理的邮件中统计。
