# 模板：代码循环的接手包

> 来源：《循环工程》原第 11 章 11.14，2026-11-07 缩编改写时外移；字段说明见新第 7 章 7.9。

Agent 达到尝试上限或任务转人工时，应按下面的模板整理接手包。模板只列出需要填写的证据字段，不是可执行代码，不会自动读取仓库或提交结果：

```text
任务与基线提交：
复现命令、环境与真实退出码：
失败日志的最小相关片段：
已经排除的原因与证据：
每次尝试的补丁和验证结果：
当前工作树差异：
未确认假设：
需要扩大哪些文件、权限或环境：
建议下一步，不自动执行：
```

好的接手包能让开发者少做重复调查。它应保留具体命令、版本和差异，不能只用一句“尝试多种方案仍失败”概括整个过程。
