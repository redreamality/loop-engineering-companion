# 编码工具迁移：切换条件核对清单

> 来源：《循环工程》原第 11 章 11.18“切换条件”，2026-11-07 缩编改写时外移；正文见新第 7 章 7.11。

切换到新编码工具（或新运行形态）前，要满足：

- 任务身份和状态能在工具之外继续读取；
- 仓库指令、运行镜像与权限都有明确记录和配置；
- 同一评测集达到约定质量门槛；
- 新系统能生成完整接手包，并在中断后保持任务幂等；
- 已为服务身份重新配置 PR、推送和机密凭证的访问权限；
- 有回退到人工处理或旧运行形态的办法。

迁移完成后，按保留政策停用旧会话并撤销旧密钥。历史任务要保留工具与模型版本，以便发生事故后判断问题来自规则、环境还是执行器的变化。
