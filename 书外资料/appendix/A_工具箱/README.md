# 循环工程工具箱

> 原附录 A 全文拆分为单文件外移至配套资料（2026-11）；文中章号已按新版调整。本目录把书中的任务卡、循环合同、验证表、状态表、运行记录和治理表集中到一起。这里的 Agent，指在目标、上下文、工具和权限范围内选择步骤并执行任务的主体；模型本身不承担任务身份、长期状态或组织授权。除非另有明确说明，`text`、`json` 围栏中的内容都是不可执行的模板或记录示例，不代表现成命令、配置或平台能力。模板不是越完整越好。第一次使用时，只填写能改变执行或判断的字段；某个字段连续三轮无人使用，就删除或说明保留原因。

## A.1 使用方式

工具箱有三种用法。

**从零搭建**：先用"工作影随"（Work Shadowing）记录人工过程，再填任务选择卡、循环合同和三轮试运行记录。工作影随是跟随真实人工任务，从开始信号到业务结果记录实际动作，用来建立人工基线；它不是让自动化在生产环境旁观运行。不要一开始填写组织治理的全部表格。

**修理现有自动化**：选最近一次失败，沿任务身份、交付、验证、状态、副作用和调度逐张查断点。只补能阻止同类失败的字段或控制。

**组织评审**：从循环目录中随机选一项真实任务，用证据索引、权限表、成熟度表和退役表核对。架构图只能提供导航，不能代替运行证据。

每张表都应有版本、负责人和最近复核日期。模板副本属于具体循环，不要让所有团队共同编辑一份没有作用域的"万能配置"。
