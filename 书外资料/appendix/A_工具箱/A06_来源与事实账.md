# A.6 来源与事实账

> 原附录 A A.6 节外移；文中章号已按新版调整。

按需要核查的主张或字段建记录，不按整篇文档笼统登记。"原始位置"和"来源版本"让验证人找回依据，"适用对象和范围"限制它可以支持哪些判断，"依赖该主张的产物"则用于找到需要复核的下游结果。事实暂时无法确认时保留假设身份，不能因为填了来源链接就升级为权威事实。

```text
claim_id：
主张或字段：
类型：权威事实 / 来源观点 / 作者判断 / 假设
来源主体：
原始位置：URL / 文档 ID / 页码 / 行或字段
来源版本 / 发布日期：
读取时间：
适用对象和范围：
许可或数据用途限制：
已知限制：
复核日期或失效条件：
依赖该主张的产物：
验证人 / 验证方式：
```

事实账适合内容、合同、产品能力和政策任务。重点追踪会改变决定、容易过期或可能造成风险的主张，日常常识可以不加引用。

来源页面更新时，先判断相关字段是否真的变化，再按依赖关系使草稿、批准或已发布内容进入复核。页面指纹变化不等于所有主张失效。
