# A.21 最小文件包

> 原附录 A A.21 节外移；文中章号已按新版调整。

个人或小团队可以先用一个目录保存最小控制面，采购平台可以延后。下面是不可执行的文件树示意，注释说明各文件的用途，目录与平台功能需要在实际部署时另行建立：

```text
loop-name/
  README.md              # 循环合同、负责人、暂停和人工退路
  task-envelope.md       # 任务包字段
  verification.md        # 验证矩阵与样本说明
  states.md              # 状态、重试和恢复
  permissions.md         # 数据、工具和动作边界
  evals/                 # 正常、边界、故障和恶意样本
  decisions/             # 规则、风险与扩张决定
  incidents/             # 演练、近失和事故
  cost/                  # 单位经济性记录
  retirement.md          # 退役步骤
```

运行数据可以保存在表格、数据库或产品控制台，文件包只保存方法和证据索引。`Skill`、模型和供应商版本应在方法或变更记录中可回查；敏感原文、访问令牌、密钥和生产日志不要为了"资料齐全"复制进普通目录。
