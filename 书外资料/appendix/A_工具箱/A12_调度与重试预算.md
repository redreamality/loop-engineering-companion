# A.12 调度与重试预算

> 原附录 A A.12 节外移；文中章号已按新版调整。

先按触发与截止确定任务何时有资格运行，再用并发、对象互斥和预算限制实际推进。单次超时、最大尝试和总运行时限必须一起填写：一次尝试未超时，不表示累计任务仍有预算。把每项上限连接到背压、暂停或转人工的处置，并在恢复栏写明允许重开的范围，不能把恢复理解为重新获得全部预算。

模型 API 重试和业务动作重试分开。前者可能重复一段推理，后者可能重复发消息或付款。把错误分成可重试、不可重试和动作状态未知三类，并为每类写出证据、最大次数和下一状态。无法证明业务幂等时，进入状态查询或人工处理。
