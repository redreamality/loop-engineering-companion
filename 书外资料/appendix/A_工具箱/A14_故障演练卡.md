# A.14 故障演练卡

> 原附录 A A.14 节外移；文中章号已按新版调整。

```text
演练名称 / 日期：
循环与版本：
目标控制：
注入故障：
测试数据和环境：
禁止触碰的真实资源：

预期
- 发现信号：
- 状态变化：
- 被拒绝的权限或动作：
- 告警与责任人：
- 保存的证据：
- 恢复步骤：

控制生效 / 失效（写出何时拦截、何时漏过以及证据）：
人工是否能接手：

需要修复的字段、规则、权限或手册：

```

建议故障库包含：重复事件、乱序、权威事实变化、权限拒绝、外部服务超时但动作成功、验证器漏检、费用风暴、审批人缺席、供应商不可用、记忆污染和批量错误。先在测试、演练运行（dry run）或影子环境演练，资金与客户动作使用假服务；每次演练都要写出预期状态、实际状态、未覆盖的控制和回归样本。

按具体故障组织的完整演练样例，见配套仓库 [ch08/桌面演练_重复退款](../../ch08/桌面演练_重复退款.md) 与 [ch08/近失事件记录示例](../../ch08/近失事件记录示例.md)；演练发现的退化迹象，另见 [ch08/安全控制退化指标](../../ch08/安全控制退化指标.md)。
