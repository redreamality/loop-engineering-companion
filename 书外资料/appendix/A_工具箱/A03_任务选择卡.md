# A.3 任务选择卡

> 原附录 A A.3 节外移；文中章号已按新版调整。

每项候选任务单独填一张卡，先用人工基线确认值得改善的环节，再把输入、完成标准和判断规则的缺口与最大影响放在一起看。"部分"需要写明缺什么、由谁补齐；无法验证完成或无人接手的任务，不能仅凭频率高就选为受控动作。最后的起步方式应受这些缺口限制，选择理由也应能解释为什么不采用权限更高的方案。

```text
候选任务（一个可稳定识别的业务任务）：
业务消费者：
当前频率 / 月度数量（注明统计窗口和分母）：
人工起点和终点：
输入是否可取得且稳定：是 / 部分 / 否
完成标准是否可观察：是 / 部分 / 否
主要判断能否写清：是 / 部分 / 否
最大单次影响（金额、对象数、数据范围或时限）：
外部副作用：
数据敏感性（个人、客户、财务、内部或公开）：
可撤销性（能否回滚；不能回滚时的补偿路径）：
异常是否有负责人（写角色和接手入口）：
人工基线：时间 / 错误 / 等待 / 成本
建议起步：不自动化 / 辅助 / 草稿循环 / 受控动作
选择或放弃理由（引用上面的证据，不只写"高频"或"低风险"）：
```

优先选择高频、边界较清楚、完成可验证、失败可恢复的任务。高频但目标含糊的工作，产出难以验证，容易堆积无用结果；低频且风险很高的工作，缺少足够样本建立评测。
