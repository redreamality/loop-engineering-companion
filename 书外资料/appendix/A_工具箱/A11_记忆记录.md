# A.11 记忆记录

> 原附录 A A.11 节外移；文中章号已按新版调整。

填写时先确定内容的类型，再确定它能被哪些任务读取和使用。"作用域"说明内容适用于谁，"可见范围"说明谁能看，两者不能互相替代；"覆盖它的权威来源"用于在事实冲突时确定应重新核对什么。到期、被更正或超出作用域的记录不应继续影响新任务，即使历史版本仍因审计需要保留。

```text
memory_id：
内容：
类型：事实 / 偏好 / 决定 / 经验候选 / 政策
来源与证据：
创建人或任务：
作用域：个人 / 客户 / 项目 / 团队 / 组织
可见范围：
有效期 / 复核日期：
覆盖它的权威来源：
哪些任务可以使用：
更正与删除入口：
历史版本：
```

一次人工改写先保存为观察，不直接升级成全局偏好。多次、同作用域、理由一致的观察可以形成规则候选，经负责人评审和样本回归后发布。

不要把完整运行日志称为记忆。日志用于还原，事实用于判断，偏好用于个性化，政策用于授权。它们的来源、权限和保留期不同。
