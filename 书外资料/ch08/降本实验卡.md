# 降本实验卡与边际成本

> 来源：原第13章 13.23。对应正文第8章 8.9 节。

一项降低费用的改动，可能增加人工工作量或出错风险。因此正式应用前，先写一张优化实验卡，把假设、基线、保护指标和停止条件一次写清：

```text
问题：邮件摘要上下文成本连续三周上升
假设：按会话增量摘要可减少重复输入，不降低事实覆盖
基线：每成功摘要全成本、人工修改率、遗漏事实数、时延
改动：仅对内部低风险邮件启用增量摘要 v2
样本：过去四周去标识化会话 + 10% 影子流量（只生成候选，不改变正式状态）
保护指标：高风险事实遗漏、错误收件人、摘要过期
成功标准：全成本下降至少 20%，保护指标不劣于容忍区间
停止条件：出现一项严重遗漏，或转人工增加超过容量
负责人 / 截止 / 回滚版本：
```

先用历史样本比较新旧策略，再进行影子运行。按任务难度分别查看实验结果，不能让大量简单邮件的良好表现掩盖少数复杂客户会话中的问题。若节省费用仅仅是因为减少了高风险验证，就应判定实验失败。

**看边际成本**

平均成本回答的是“过去每项大约花了多少”，扩容时还要看下一批任务的边际成本。队列接近上限后，新增任务可能需要调用更昂贵的模型、更频繁地重试，或安排人员夜间处理。看起来只是每月多一千项任务，实际可能还要增加一名审批值班人员。

因此，评审扩容计划时，要同时估算现有容量内再增加一百项任务的成本、超过容量上限后突然增加的成本，以及事故和返工的尾部风险。自动化规模扩大后，成本并不一定按原来的比例增长。
